# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase
projects, technical skills, experience, education, and contact information
through a clean and interactive interface.

---

## ✨ Features

- 📱 Fully responsive design
- 🌙 Dark / Light mode toggle
- 🧭 Responsive navigation bar
- 🎨 Modern and clean UI
- ✨ Smooth transitions and animations
- 🛠️ Interactive skill cards
- 🚀 Project showcase with hover effects
- 🔗 Direct links to project repositories
- 📄 Downloadable CV
- 📧 Contact section
- 📱 Mobile-friendly layout
- ⚡ Fast and lightweight frontend

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Font Awesome
- Typed.js
- Lightbox

🚀 Running the Website

Clone the repository:

```
git clone YOUR_REPOSITORY_URL 
```

Open the project folder and launch:

```text
index.html
```

The website can also be run using VS Code Live Server.
